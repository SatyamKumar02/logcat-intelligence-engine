AI / ML Capstone Project — built for $0

Logcat Intelligence Engine

A self-improving AI diagnostic system for Android OS logs: a ReAct agent diagnoses root causes from logcat/dmesg artifacts using specialized tools, every investigation becomes training data, a local 7B model gets fine-tuned with QLoRA + DPO, an eval harness gates deployment, and the model serves via an airgapped Docker image. This page replays real captured data from the project — nothing here is staged.
